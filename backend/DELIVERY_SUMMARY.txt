201 Created         - Successful POST
400 Bad Request     - Invalid input
401 Unauthorized    - Missing/invalid token
403 Forbidden       - Insufficient permissions
404 Not Found       - Resource not found
409 Conflict        - Resource already exists
500 Server Error    - Internal error

SUPPORT & TROUBLESHOOTING
================================================================================

DATABASE CONNECTION ERROR
→ Ensure MySQL is running
→ Check credentials in .env
→ Verify database exists

PORT ALREADY IN USE
→ Change PORT in .env (try 5001)
→ Or kill process: lsof -ti:5000 | xargs kill -9

TOKEN ERRORS
→ Copy full token from login response
→ Use Bearer prefix: "Authorization: Bearer TOKEN"
→ Token expires after 7 days - login again

CORS ERRORS
→ Verify FRONTEND_URL in .env
→ Check frontend is on http://localhost:5173

For more help, see README.md TROUBLESHOOTING section
